# Viluxent

Personal site for Viluxent, 9.0 TMUA holder and writer of community-made TMUA mock papers and guides.

A single self-contained page (`index.html`): a scroll-driven CRT tube through Vogel's sunflower,
Euler, Euclid, De Morgan, Lorenz, a prime corridor and a Mandelbrot dive.

Design inspired by [fojcikdominik.com](https://fojcikdominik.com/).

Hosted with GitHub Pages from the `main` branch.
